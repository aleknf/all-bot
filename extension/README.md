# AllBot Session Sync - Chrome/Edge Extension

Ekstensi browser untuk menyinkronkan sesi login **Claude Pro** dan **Gemini Advanced** dari browser Anda secara otomatis ke server AllBot VPS tanpa perlu copy-paste cookie manual.

---

## 🚀 Cara Pasang di Browser (Hanya 1 Menit)

1. Buka browser **Google Chrome**, **Brave**, atau **Microsoft Edge**.
2. Buka alamat: **`chrome://extensions`** di bilah URL browser Anda.
3. Di pojok kanan atas, nyalakan sakelar **"Developer mode"** (Mode pengembang).
4. Klik tombol **"Load unpacked"** (Muat yang belum dibongkar) di pojok kiri atas.
5. Pilih folder:
   📂 `/Users/aleknurfatman/Downloads/alek/all-bot/extension`

---

## ⚡ Cara Pakai:

1. Pastikan Anda sudah login ke [claude.ai](https://claude.ai) dan [gemini.google.com](https://gemini.google.com) di browser Anda seperti biasa.
2. Klik ikon ekstensi **AllBot Session Sync** di toolbar browser Anda.
3. Ekstensi akan otomatis mendeteksi:
   - `✓ Login Terdeteksi (Claude.ai)`
   - `✓ Login Terdeteksi (Gemini.google.com)`
4. Klik tombol **"⚡ Sinkronkan ke VPS Sekarang"**.
5. Selesai! Sesi akun Anda akan otomatis terkirim dan tersimpan di database VPS Anda.
